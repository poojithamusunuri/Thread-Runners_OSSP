About live data ProcScope takes read-only snapshots from Linux /proc. Very short-lived processes may appear between snapshots and not be captured. A visible tree root can mean its parent was not present in the same snapshot.

PROCESS ACTIVITY

Activity Timeline

See changes between process snapshots, with a clear label explaining how each item was detected.

How to read this timeline

Each entry is labelled by how it was detected. Snapshot-inferred entries are estimated by comparing reads of /proc; observed entries come from kernel process events when event mode is available. Snapshot comparisons can miss very short-lived processes, and event collection can be unavailable or lose events. A process missing from a snapshot may have exited or may simply have been unreadable.

Privacy and accuracy

Reports are generated locally. Command-line arguments can contain sensitive data, so redaction is enabled by default. Snapshot comparisons are best-effort and are not an atomic view of the system.
